# Production Repository Instructions

This repository is the approved YoToConn skill supply chain.

- Never create or experiment with a new skill directly in this repository.
- Every skill must identify its development source commit and approved version.
- Do not commit secrets, customer data, raw device output, or unrestricted tools.
- Preserve approval records and catalog consistency.
- Run `python3 scripts/validate_release.py` before claiming release readiness.
- Production changes require pull-request review and explicit human approval.
